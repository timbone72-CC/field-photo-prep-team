# Field Work Hub Admin Dashboard

This folder contains the hosted FWH Admin dashboard for work-order dispatch, reassignment, Contractor setup links and receipt visibility.

Live dashboard: https://timbone72-cc.github.io/field-work-hub/

It uses only the Supabase project URL and publishable key. The existing session helper preserves the signed-in session in the current browser tab. Passwords and setup links are never persisted by the app.

Supabase RLS and narrow RPCs enforce server-controlled role, organization and assignment authority. Automatic updates run while the signed-in page is visible and online and preserve unsaved edits.

The Contractor setup page requires a valid link generated by the authenticated Admin. The original Field Photo Prep app is separate.
