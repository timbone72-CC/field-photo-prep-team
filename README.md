# Field Work Hub
Multi-user field photo workflow for work-order assignment, offline capture, secure photo sync, and admin oversight.

- Repository: https://github.com/timbone72-CC/field-work-hub
- Admin dashboard: https://timbone72-cc.github.io/field-work-hub/
- Contractor setup page: https://timbone72-cc.github.io/field-work-hub/contractor-invite.html (a valid Admin-issued setup link is required).

The Android client is **Field Work Hub Internal**. Its existing package and stable test signer are preserved. The original Field Photo Prep app is a separate project.
